# Overview

With the rapid rise of online fraud, phishing attacks, impersonation scams, and AI-generated deception, users often struggle to determine whether a message, email, or voice interaction is legitimate.

ShadowTrace was built to solve this problem through an AI-assisted threat analysis system capable of detecting suspicious behavioral patterns and scam indicators instantly.

The platform combines:

- Real-time AI analysis
- Threat probability scoring
- Scam pattern detection
- Emotional manipulation analysis
- Cybersecurity-focused UI/UX
- Interactive threat dashboards

---

# Core Features

## Live Threat Scanner

Analyzes suspicious messages and scam texts in real time.

### Detects:

- Scam language patterns
- Emotional manipulation
- Fake urgency tactics
- Impersonation attempts
- Financial fraud indicators
- Social engineering attacks

---

## Phishing Email Detector

AI-powered phishing email analysis system.

### Detects:

- Fake banking emails
- Credential harvesting attempts
- Suspicious links
- Fake login portals
- Threatening or urgent language
- Social engineering techniques

---

## AI Voice Fraud Detector

Analyzes suspicious voice call transcripts and voice fraud scenarios.

### Detects:

- Family emergency scams
- AI impersonation attempts
- Panic-based manipulation
- Fake authority scams
- Forced urgency tactics
- Isolation and pressure tactics

---

## URL Threat Detection

Scans suspicious URLs and identifies potentially dangerous websites.

### Detects:

- Phishing domains
- Fake login pages
- Unsafe redirects
- Suspicious domain structures
- Scam-related keywords

---

## Threat Probability Meter

Displays dynamic risk scores and visual threat probability indicators for easier user understanding.

---

## Threat History Dashboard

Maintains previously analyzed threats for quick review and monitoring.

# Installation

## Clone the Repository

```bash
git clone https://github.com/your-username/shadowtrace.git
```

---

## Navigate Into Project

```bash
cd shadowtrace
```

---

## Install Dependencies

```bash
npm install
```

---

## Create Environment File

Create a `.env.local` file in the root directory:

```env
GEMINI_API_KEY=your_api_key_here
```

---

## Start Development Server

```bash
npm run dev
```

---

# Deployment

This project is optimized for deployment on:

- Vercel

## Deploy Steps

1. Push project to GitHub
2. Import repository into Vercel
3. Add environment variable:

```env
GEMINI_API_KEY=your_api_key_here
```

4. Deploy project

# Problem Statement

Cyber fraud and AI-generated scams are increasing rapidly across messaging platforms, emails, phone calls, and social media.

Most users lack the technical knowledge required to identify sophisticated phishing attacks or emotional manipulation scams.

ShadowTrace aims to provide a simple, accessible, and intelligent cybersecurity assistant that helps users detect threats before becoming victims.
